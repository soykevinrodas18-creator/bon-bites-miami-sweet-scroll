# Bon Bites Miami: Sweet Scroll

Crea una página web moderna, premium, atractiva y altamente visual para BON BITES Miami, tomando como referencia principal la identidad visual de su perfil de Instagram:

https://www.instagram.com/bonbites.miami/

OBJETIVO

Diseñar una página web que convierta visitantes de Instagram en clientes. La web debe sentirse como una extensión natural del Instagram de BON BITES, manteniendo su personalidad, colores, estilo fotográfico, tipografías y estética de marca.

NO crear una página genérica de restaurante. La identidad visual debe sentirse específica de BON BITES.

IDENTIDAD VISUAL

Analiza y reproduce de manera consistente:

Colores principales utilizados en Instagram.

Colores secundarios y colores de acento.

Tipografías utilizadas en publicaciones y branding.

Estilo del logotipo.

Estilo de fotografía.

Formas, bordes y elementos gráficos.

Estilo de los iconos.

Estética general de las publicaciones.

Espaciado y composición visual.

Personalidad de la marca.

Utiliza una paleta de colores coherente con Instagram y mantenla en toda la página.

ESTILO

Crear una estética:

Premium

Moderna

Elegante

Apetitosa

Minimalista pero llamativa

Visualmente atractiva

Mobile-first

Con fotografías grandes de los productos

Con microanimaciones sutiles

Con excelente jerarquía visual

Evitar diseños corporativos genéricos.

HERO SECTION

Crear una primera sección impactante.

Incluir:

Logo de BON BITES.

Fotografía principal de producto en alta calidad.

Título grande y atractivo.

Subtítulo corto explicando la propuesta de BON BITES.

Botón principal: "ORDER NOW"

Botón secundario: "VIEW MENU"

Iconos de Instagram y otras redes sociales.

Animaciones suaves al cargar.

La fotografía debe ocupar una parte importante del hero y hacer que el producto sea el protagonista.

NAVEGACIÓN

Crear un navbar elegante y limpio.

Elementos:

Logo BON BITES

Home

Menu

About

Gallery

Contact

Instagram

Botón "Order Now"

En móvil utilizar menú hamburguesa.

El navbar debe permanecer visible durante el scroll mediante sticky navigation.

SECCIÓN MENU

Crear una sección visual para mostrar los productos.

Cada producto debe incluir:

Fotografía grande

Nombre

Descripción corta

Precio

Botón "Order Now"

Utilizar cards modernas y elegantes.

Agregar filtros por categorías si existen diferentes tipos de productos.

Las imágenes deben ser protagonistas.

SECCIÓN BEST SELLERS

Crear una sección:

"OUR FAVORITES"

Mostrar los productos más populares con cards grandes.

Cada card debe incluir:

Imagen

Nombre

Descripción

Precio

CTA

Agregar una pequeña etiqueta como:

"BEST SELLER"

cuando corresponda.

SECCIÓN ABOUT

Crear una sección "ABOUT BON BITES".

Utilizar una combinación de:

Fotografía de la marca/productos.

Texto corto.

Elementos gráficos de la identidad visual.

El texto debe comunicar personalidad, calidad y la experiencia de BON BITES.

No utilizar párrafos excesivamente largos.

GALERÍA

Crear una galería visual inspirada en el feed de Instagram.

Utilizar un grid dinámico tipo editorial:

Fotografías cuadradas.

Fotografías verticales.

Fotografías horizontales.

Diferentes tamaños de imágenes.

Crear un efecto hover elegante.

Agregar botón:

"FOLLOW US ON INSTAGRAM"

con icono de Instagram.

El botón debe dirigir al Instagram oficial:

https://www.instagram.com/bonbites.miami/

SOCIAL MEDIA

Incluir iconos oficiales y modernos para:

Instagram

TikTok

Facebook

Los iconos deben utilizarse de forma elegante y consistente.

No utilizar iconos genéricos que desentonen con la identidad visual.

CALL TO ACTION

Crear una sección grande de conversión:

"READY FOR A BITE?"

o una frase similar alineada con la personalidad de BON BITES.

Incluir:

"ORDER NOW"

y

"CONTACT US"

como botones.

Utilizar una fotografía de producto como fondo o elemento principal.

CONTACT SECTION

Crear una sección de contacto con:

Instagram

Teléfono, si está disponible

Email, si está disponible

Ubicación, si está disponible

Horarios, si están disponibles

Botón de contacto

Botón de Instagram

Google Maps si existe una ubicación física

No inventar información que no esté disponible.

FOOTER

Footer elegante y minimalista.

Incluir:

BON BITES

Menu

About

Contact

Instagram

TikTok

Facebook

Agregar:

© 2026 BON BITES. All rights reserved.

EXPERIENCIA MÓVIL

La página debe estar especialmente optimizada para teléfonos porque la mayoría de los visitantes probablemente llegarán desde Instagram.

En móvil:

Hero vertical.

Botones grandes.

Imágenes optimizadas.

Menú fácil de navegar.

CTA "ORDER NOW" siempre accesible.

Tipografía perfectamente legible.

Cards adaptadas a una columna.

Animaciones rápidas y ligeras.

ANIMACIONES

Agregar microinteracciones profesionales:

Fade-in al hacer scroll.

Parallax ligero en imágenes.

Hover en botones.

Scale suave en productos.

Transiciones entre secciones.

Animación del navbar.

Smooth scrolling.

Las animaciones deben ser elegantes y rápidas. No sobrecargar la página.

IMÁGENES

Usar fotografías de comida/productos de alta calidad, estilo editorial y comercial.

Características:

Fotografía gastronómica profesional.

Iluminación natural.

Colores apetitosos.

Texturas visibles.

Fondos limpios.

Composición premium.

Alta resolución.

IMPORTANTE:

Si se proporcionan fotografías reales del Instagram de BON BITES, utilizarlas como referencia principal para mantener consistencia visual.

No utilizar fotografías aleatorias que contradigan la identidad de la marca.

ICONOGRAFÍA

Utilizar una librería moderna de iconos como Lucide Icons o equivalente.

Los iconos deben ser:

Minimalistas.

Consistentes.

Elegantes.

Del mismo peso visual.

Para redes sociales utilizar los logos correspondientes de cada plataforma.

TIPOGRAFÍA

Seleccionar tipografías que reproduzcan lo más fielmente posible el estilo visual de BON BITES observado en Instagram.

Utilizar máximo:

1 tipografía principal.

1 tipografía secundaria/acento.

Crear una jerarquía clara entre:

H1 → H2 → H3 → body → captions → buttons.

UX / CONVERSIÓN

La página debe estar diseñada para convertir.

Prioridades:

Mostrar el producto inmediatamente.

Hacer que el menú sea fácil de encontrar.

Facilitar el pedido.

Mostrar Instagram.

Generar confianza.

Mostrar fotografías apetitosas.

Facilitar contacto.

Los CTA principales deben ser:

"ORDER NOW"

"VIEW MENU"

"FOLLOW US"

SEO

Implementar:

SEO title.

Meta description.

Open Graph.

Alt text para imágenes.

URLs limpias.

Schema markup apropiado para el negocio si la información disponible lo permite.

Optimización de velocidad.

Lazy loading de imágenes.

TECNOLOGÍA

Construir utilizando:

React

Next.js

Tailwind CSS

Componentes reutilizables

Diseño responsive

Código limpio y organizado

La página debe estar preparada para producción.

RESULTADO FINAL

El resultado debe parecer una página web profesional creada específicamente para una marca gastronómica moderna de Miami.

Debe transmitir inmediatamente:

BON BITES = PRODUCTO + CALIDAD + ESTILO + MIAMI + EXPERIENCIA

No quiero una plantilla genérica.

Quiero una experiencia visual que haga que alguien que llega desde Instagram piense:

"Esto se ve increíble. Quiero probarlo."

Prioriza fotografías, branding, conversión y experiencia móvil.
